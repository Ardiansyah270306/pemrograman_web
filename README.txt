# Portofolio Pribadi Ardiansyah

Website portofolio sederhana menggunakan HTML, CSS, dan JavaScript.

## Struktur file
- `index.html` — struktur dan konten halaman.
- `style.css` — warna, tata letak, responsivitas, dan animasi.
- `script.js` — menu HP, animasi saat scroll, navigasi aktif, tahun otomatis, dan tombol kembali ke atas.

## Cara menjalankan di VS Code
1. Ekstrak ZIP ini ke folder yang mudah ditemukan.
2. Buka Visual Studio Code.
3. Pilih **File > Open Folder**, lalu pilih folder `portofolio_ardiansyah`.
4. Buka `index.html`.
5. Jika menggunakan ekstensi **Live Server**, klik kanan `index.html` lalu pilih **Open with Live Server**.
6. Jika belum memakai Live Server, buka `index.html` langsung dari File Explorer dengan browser.

## Sebelum dikumpulkan
- Ganti placeholder foto profil dengan foto milikmu.
- Ganti email contoh `emailkamu@example.com` dengan email yang benar.
- Ganti tautan media sosial placeholder.
- Ubah bagian proyek menjadi karya yang benar-benar pernah dibuat. Jika belum ada proyek lain, jelaskan bahwa proyek tersebut masih dalam tahap belajar.
- Sesuaikan deskripsi dan tingkat kemampuan agar akurat.

Font dari Google Fonts memerlukan koneksi internet. Jika internet tidak tersedia, browser akan menggunakan font cadangan.

## Ringkasan fungsi
- HTML: menyusun konten dan bagian halaman.
- CSS: mengatur desain, warna gelap, tata letak responsif, hover, dan animasi.
- JavaScript: mengontrol menu mobile, animasi ketika elemen muncul, navigasi aktif, tahun footer, dan tombol kembali ke atas.
